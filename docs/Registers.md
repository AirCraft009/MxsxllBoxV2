## Registers

> MxsxllBox v2 has 16 64bit GPO regs
> They can all be split into 32bit regs \
> which can then be split into h & l 16 bit regs

### Register List

- MAX (accumulation)
  - Return values from functions or syscalls
- MBX (base register)
  - Base register for memory offsets
- MSP
  - Stack Pointer 
- MBP
  - Stack Base Pointer
